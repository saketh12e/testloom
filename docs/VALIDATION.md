## What the regressions cover

The 30-test suite includes snapshot exclusions; original-source preservation; path traversal, symlink and overwrite rejection; explicit requirement preservation; query-normalized navigation checks; missing/unsupported/redacted input rejection; quoted credential redaction; immutable generated bytes; missing/skipped/retry-only discovery rejection; literal process arguments; timeout and cancellation; descendant-process termination without harming unrelated groups; recorder action ordering and deduplication; authentication and masking of recorder packets; bounded stop behavior; packet and ledger size bounds; and application shutdown awaiting active work.

## Reproduce

```sh
npm ci
npm run browsers
npm run check
npm run test:journey
npm run test:desktop
```

The native desktop check requires an interactive graphical Mac session and free loopback ports 4318 and 9437. Java instructions and prerequisites are in [the Java example](../examples/java/README.md). The Java integration uses port 4329. Codex validation requires an authenticated Codex CLI and consumes the account's model usage:

```sh
npx tsx tests/codex.smoke.ts
npx tsx tests/codex.verify.ts
```

The package can be checked directly:

```sh
npm run package:mac
JOURNEYPROOF_EXECUTABLE="$PWD/release/mac-arm64/JourneyProof.app/Contents/MacOS/JourneyProof" npm run test:desktop
```

Scripts write detailed local evidence to ignored `work/` files. They use synthetic cart data. The public summary intentionally excludes machine-specific directories and raw account/provider output. The tag identifies the source release; asset checksums identify the downloads.

## Practical limits

These checks establish the demonstrated flows and bounded regression behavior. They do not establish complete business-rule coverage, resilience to every hostile page, arbitrary-framework compatibility, multi-browser coverage, or absence of flakiness. The recorder is still page-world instrumentation with mitigations. Verification executes trusted project code with local user rights. Custom commands do not automatically prove generated-test discovery. Intel Macs and other macOS versions were not exercised. The app is not Apple Developer signed or notarized. Read [Limitations](LIMITATIONS.md) before company use.
